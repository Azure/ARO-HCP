Measurement definitions and contribution warnings ({{len .Contributions.Warnings}})

{{.Contributions.NewLabel}} compares full physical label sets seen in (run start, run end] against {{if .Contributions.BaselineValid}}the explicit (baseline start, baseline end] window{{else if not .Data.Context}}the preceding 12 hours at run start (legacy evidence, not a quiet baseline){{else}}an unavailable baseline{{end}}, before grouping. It is not first-ever creation, subtraction of grouped counts or proof this run caused the increase. A group present in both periods need not contain identical physical label sets. Baseline-only groups remain visible even when their run weight is zero.

Stored samples counts the exact full run, including the final {{.Trailing}} seconds, not counter increments or histogram observations. Baseline samples cover their own explicit window. Rates divide by their own durations; raw sample totals across unequal windows are not subtracted.

Namespace and hostedcontrolplane must match a literal inventory entry; no namespace is synthesized from a customer name. A matching HCP field can identify a customer when the namespace is shared or absent; conflicting mapped fields are Ambiguous, never auto-assigned. Canonical grouped joins are case-insensitive for AMW while display spelling is preserved. A successful, warning-free count response implies zero for an absent group; failed, missing, malformed or partial responses do not. Invalid counts or duplicate canonical groups withhold that metric's measure. Discrepant counts are warned, never clamped.
