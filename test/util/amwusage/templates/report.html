Read the measurements correctly

Platform: one-minute maxima from {{utc .Data.Run.PlatformStart}} to {{utc .Data.Run.PlatformEnd}} (end exclusive). Dashed vertical lines mark the run. ActiveTimeSeries is a trailing 12-hour inventory, not this run's distinct-series count.

Samples: count_over_time counts stored samples, not counter increments, API requests, CPU usage, or histogram observations. Each bucket series and each stored replica label set is counted separately. The chart is a five-minute sample count divided by five, in samples/minute.

First sample evaluation is start + 5 minutes, so no pre-run lookback is included. The run interval is (start, end]; {{.Windows}} complete five-minute windows are plotted. The final {{.Trailing}} seconds are omitted from sample timelines but included in exact-run cardinality and the new full-window stored-sample query when collected. Missing group/evaluation values are not zero-filled.

Any explicit nonfinite or invalid returned group value makes that sample evaluation unavailable, not a partial total. Such evaluations are excluded from sample subtotals and peaks. An absent series is distinct: remaining returned groups can still be summed without imputing the absent group. Any invalid cardinality group makes the entire cardinality total unavailable. Duplicate points within a group also withhold that evaluation.

Quota comparisons require exactly one usage and one limit series, paired numeric minutes, positive limits and PT1M intervals. Multiple physical series remain visible but are not summed or arbitrarily paired. A quota crossing in paired maxima is not itself proof of dropped samples.

What this analysis does not establish

  • No all-workspace top-N, full fan-out or extrapolation from selected metric names to unknown metrics.
  • No causal attribution of regional ingestion to this job. Services workspaces can include management-cluster telemetry. Run-owned classification requires the supplied literal namespace inventory; absent labels and unmapped attempts remain unassigned.
  • No HA deduplication. Distinct stored series count physical label sets present in AMW; upstream ingestion deduplication is not reversible.
  • No proof of a quiet period before the run, independent client pacing, or complete underlying ingestion merely from successful response status.
  • No histogram event count derived from bucket-series sample counts. No dropped-event total derived by adding minute maxima.
  • Regional quota headroom and incomplete LimitThrottling reason coverage cannot prove zero dropped samples. Even complete evidence supports only the observed interval and recorded series.
